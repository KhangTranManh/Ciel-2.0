# Server image dependency set — derived from the root requirements.txt, with
# hardware-bound packages removed. A headless container has no display and no
# microphone, so these would either fail to import or do nothing useful:
#   pyautogui, pyperclip   -> screen/mouse control (vision_ops, disabled via
#                             DISABLED_SKILL_MODULES=vision_ops; not installed
#                             so the image doesn't need any X11/display libs)
#   sounddevice            -> mic capture (needs PortAudio + an actual input
#                             device; core/voice_input.py is lazy-imported by
#                             the CLI only, main_api.py never touches it)
#   faster-whisper         -> local STT model, only used behind sounddevice
#   SpeechRecognition      -> STT fallback, same story
# edge-tts is KEPT: core/speech_output.synth_to_bytes() calls Microsoft's cloud
# TTS and returns raw bytes over the websocket — no local audio hardware needed,
# and main_api.py does use it.
#
# If you re-enable vision or voice-input for this deployment, add the relevant
# packages back here (and drop vision_ops from DISABLED_SKILL_MODULES) rather
# than switching back to the root requirements.txt wholesale.
